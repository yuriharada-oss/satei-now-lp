# 査定ナウ LP

LINEミニアプリ認証・LINEヤフー広告審査 対応のランディングページ。
「査定ナウLPデザイン」セッション（`査定ナウ関連/lp_satei-now/`）の成果物を引き継ぎ、
買取大吉 都立大学店 公式LP（https://toritsu-daigaku.kaitoridaikichi-onsite.jp/）の情報を反映したもの。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | LP本体（FV／査定の流れ4ステップ＋実画面スクショ／取扱品目／手数料・キャンセル／ご利用にあたって／FAQ／運営者情報） |
| `assets/css/style.css` | LP本体のスタイル（index.html から分離） |
| `assets/css/subpage.css` | 下層ページ共通スタイル |
| `tokusho.html` | 特定商取引法に基づく表記（ミニアプリ内の表記に準拠） |
| `privacy.html` | プライバシーポリシー（同上） |
| `terms.html` | 利用規約（同上） |
| `assets/imgs/` | ロゴ・サティ画像・アプリ実画面スクリーンショット（app-step1〜4.webp ほか予備2枚）＋ OGP画像 `opg-img.png` |

アプリ実画面スクリーンショットは、`satei-now/asset-app/asset-user` をローカル起動し
デモデータ（App.jsx 内の SEED）を一時的に表示して撮影したもの（390×844 @2x）。
本番データでの撮り直しも可（その場合は同名で差し替えるだけ）。

## 制作指示書からの意図的な変更点

- 指示書②の4ステップは「宅配キット」前提だったが、**査定ナウの実サービスは店頭・出張買取のみ（宅配なし）**
  （業務マニュアル・ミニアプリ実装で確認）。ステップは実態に合わせて
  「撮る → 概算金額 → 来店予約・出張申込み → 本査定・現金支払い」とした。
  広告クリエイティブ（来店・出張買取に対応）とも一致する。
- 同様に、宅配買取前提の「クーリングオフ義務なし」記載は行わず、
  出張買取＝訪問購入の8日間クーリング・オフを明記（ミニアプリの特商法表記と一致）。
- 利用規約はミニアプリ内の条文をそのまま転載（アプリ側が第6条欠番のため、本LPも欠番。
  気になる場合はアプリ側と同時に修正すること）。
